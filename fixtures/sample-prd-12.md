# Proving Suite PRD (12 tasks)

Twelve disjoint requirements for the merge-queue proving run.

## Proving Suite

A synthetic product used only to exercise parallel workers, path locks, and land-on-base.

### Requirements

1. Document signup flow for email and password
2. Document session expiry after seven days
3. Document service-account API key issuance
4. Document note creation with title and body
5. Document listing notes for the current user
6. Document markdown rendering on note read
7. Document primary button with loading state
8. Document text input with label and error
9. Document spacing tokens in the styleguide
10. Document password reset email flow
11. Document note soft-delete and restore
12. Document design-token color primitives
